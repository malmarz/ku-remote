📝 الاختبارات عن بُعدOnline exams مودل وProctorio وSafe Exam Browser وRespondusMoodle, Proctorio, Safe Exam Browser, Respondus ›

لأعضاء هيئة التدريسFor faculty

  1. أنشئ الاختبار في مودل: Activities ← Quiz، واختر أحد ثلاثة خيارات: Safe Exam Browser (من إعدادات الاختبار)، أو Respondus LockDown Browser (من الكتلة؛ لا تفعّل SEB معه في الوقت نفسه)، أو Proctorio (متصفح Chrome مع الأداة الخارجية Secure Exam Proctor).
  2. طالب واجه مشكلة تقنية؟ Quiz ← Overrides ← Add user override وامنحه محاولة أخرى.
  3. الخطوات الكاملة في دليل مودل لعضو هيئة التدريس (PDF).
  4. لاستخدام Respondus في مختبر الجامعة، تواصل مع مكتب الدعم الفني قبل الاختبار ليُثبَّت البرنامج.
  1. Build the exam in Moodle: Activities → Quiz, then choose one of three options: Safe Exam Browser (Quiz settings), Respondus LockDown Browser (block; don’t enable SEB at the same time), or Proctorio (Chrome plus the Secure Exam Proctor external tool).
  2. A student had a technical problem? Quiz → Overrides → Add user override and allow another attempt.
  3. Full steps: Faculty Moodle Guide (PDF).
  4. For Respondus in a KU lab, contact the IT helpdesk before the exam so the app is installed.

للاستفسار:Questions: elc@ku.edu.kw

للطلبةFor students

قد تُراقَب الاختبارات عبر Proctorio: استخدم متصفح Google Chrome وثبّت إضافة Proctorio قبل الاختبار. شاهد فيديو مركز التعليم الإلكتروني.

Online exams may use Proctorio: use Google Chrome with the Proctorio extension installed before the exam. Watch the E-Learning Center video.

  1. افتح الاختبار في المقرر ← Attempt quiz.
  2. اقرأ رسالة المدة الزمنية ← Start attempt.
  3. أجب، ثم Next page.
  4. Finish attempt ← Submit all and finish (أكّد مرتين).
  1. Open the quiz in the course → Attempt quiz.
  2. Read the time-limit message → Start attempt.
  3. Answer, then Next page.
  4. Finish attempt → Submit all and finish (confirm twice).
انقطع الاتصال أو حدث خلل أثناء الاختبار؟ تواصل فوراً مع أستاذ المقرر؛ يمكنه منحك محاولة جديدة. If the connection drops or something fails mid-exam, contact your instructor immediately. They can grant a new attempt.
🏠 العمل من المنزل (VPN)Work from home (VPN) للموظفين وأعضاء هيئة التدريسFor staff and faculty ›
قدّم الطلب الآن. الموافقة تستغرق وقتاً، فلا تنتظر حالة الطوارئ. Request it now. Approval takes time. Do not wait for an emergency.

الخدمة متاحة لأعضاء هيئة التدريس والموظفين فقط.VPN is available to faculty and staff only.

  1. اطلبه عبر SupportMe: Security Services (خدمات الأمن) ← VPN Request (طلب VPN). يسألك النموذج عن الخدمة المطلوبة (SSH، RDP، SIS، HRFS، HSC library، Trasolat، Archive، Share Folder، Custom)، وهل هو لـ Server أم PC، وعنوان (عناوين) IP المطلوب الوصول إليها، وتاريخَي البدء والانتهاء. نصيحة: إن لم تعرف عنوان IP فاسأل مسؤول تقنية المعلومات في إدارتك.
  2. ثبّت Ivanti Secure Access Client (كان يُعرف سابقاً بـ Pulse Secure). سجّل الدخول إلى ku-vpn.ku.edu.kw وستُرشدك البوابة إلى تنزيله، أو يُنزَّل تلقائياً إن لم يكن مثبتاً.
  3. عنوان الخادم: ku-vpn.ku.edu.kw
  4. سجّل الدخول ببريدك الجامعي كاملاً (name@ku.edu.kw)، وليس الرقم الجامعي أو الوظيفي، وبكلمة مرورك الجامعية.
  5. وافق على طلب الدخول في Microsoft Authenticator؛ التحقق بخطوتين إلزامي على VPN منذ 3 سبتمبر 2026.
  1. Request it via SupportMe: Security Services → VPN Request. The form asks which service you need (SSH, RDP, SIS, HRFS, HSC library, Trasolat, Archive, Share Folder, Custom), whether it is for a Server or PC, the IP address(es) to reach, and a start and expiry date. Tip: if you don’t know the IP address, ask your department’s IT contact.
  2. Install the Ivanti Secure Access Client (previously Pulse Secure). Sign in at ku-vpn.ku.edu.kw: the portal guides you to the download, or downloads the client automatically if it is not installed.
  3. Server address: ku-vpn.ku.edu.kw
  4. Sign in with your full university email (name@ku.edu.kw), not your KU ID or employee ID, and your university password.
  5. Approve the sign-in in Microsoft Authenticator. MFA is required on VPN since 3 Sep 2026.
على أجهزتك الشخصية فقط. لا تستخدمه أبداً على أجهزة الفنادق أو المقاهي أو الأجهزة المشتركة. Your own personal devices only. Never on hotel, café or shared computers.
